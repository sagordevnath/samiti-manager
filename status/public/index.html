এই পেজটি ডিপ্লয় করা API-এর স্বাস্থ্য পরীক্ষা করে এবং আপটাইম ইতিহাস দেখায় — সেই সঙ্গে নিজের নজরদারি কতটা ছিল তাও দেখায়।
This page checks the deployed API's health endpoint and shows its uptime history — including how much of that time it was itself able to watch.

স্যাম্পল সংগ্রহ: প্রতি ১০ মিনিটে keep-alive workflow, এবং পেজ দেখলে সর্বোচ্চ ১ মিনিট পুরনো একটি নমুনা। ইতিহাস এই পেজের নিজের ডেটাবেসে রাখা হয় — যে সার্ভিস পরীক্ষা করা হচ্ছে তার ভেতরে নয়, তাই API বন্ধ থাকলেও ইতিহাস সত্য থাকে।
Samples come from the keep-alive workflow every 10 minutes plus at most one per visit; history is stored by this page rather than by the API it watches, so it stays truthful while the API is down — and because that storage is this page's own server, a window in which nothing was stored is reported above as a blind spot rather than passed off as uptime. The two sources are counted apart: scheduled coverage and the workflow's own gaps are the workflow's samples alone, so a tab left open — which probes every minute — cannot cover a run that never happened.
